# RAJONE by Raj Realty Group

Static, cinematic website for RAJONE, Charkop. Plain HTML, CSS and JavaScript, with no build step.

- `index.html`: the page (hero scroll film, 3D tower spin, step-inside flythrough, residences, amenities, location)
- `styles.css`, `film.js`, `motion.js`, `tower3d.js`: styles and scroll motion
- `assets/`: images, cutouts, the tower spin frames and the scrub videos
- `reference/` and `STUDY.md`: the original design reference and study notes
- `backups/`: time-stamped snapshots taken before each change

To deploy on GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
